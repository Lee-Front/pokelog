# Encounter Pool Balancing Design

Date: 2026-04-14

## Goal

905종 중 현재 198종(22%)만 인카운터 가능한 풀을 ~445종으로 확장.
종 분류별 적절한 weight를 배정하고, 리전별로 해당 세대 포켓몬을 배치.

## Weight 기준

| 분류 | Weight | 비고 |
|------|--------|------|
| 흔한 기본 포켓몬 | 80-100 | 찌르꼬, 꼬렛 등 초반 루트 |
| 일반 기본 포켓몬 | 40-70 | 대부분의 기본형 |
| 비교적 희귀 기본 | 15-30 | 라프라스, 헤라크로스 등 |
| 중간 진화 | 10-25 | 피카츄, 피존 등 |
| 최종 진화 (야생 출현) | 5-15 | 라따뇨, 깨비참 등 |
| 교환 진화체 | 5-10 | 후딘, 괴력몬 등 |
| 베이비 | 10-20 | 피츄, 토게피 등 |
| 스타터 기본형 | 8-15 | 이상해씨, 파이리 등 |
| 스타터 중간 | 4-8 | |
| 스타터 최종 | 2-4 | |
| 화석 | 3 | 극악 카테고리 |
| 전설 | 2 | 극악 카테고리 |
| 환상/울트라비스트 | 1 | 최극악 카테고리 |

## 레벨 범위 원칙

| 분류 | 레벨 범위 |
|------|----------|
| 기본 포켓몬 | 2-10 |
| 중간 진화 | 15-30 |
| 최종 진화 | 30-50 |
| 전설/환상 | 40-60 |
| 화석 | 15-25 |
| 베이비 | 1-5 |

## 구현 방식

`scripts/generate-encounter-pools.mjs` 스크립트 작성:
1. species.json 로드
2. evolution.json으로 진화 단계 분류
3. 종별 weight/level 자동 산출
4. 세대별로 리전 파일 생성
5. regional variant도 해당 리전에 포함
